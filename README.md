# advanced-sql-sales-analysis
This project uses advanced SQL techniques to analyse customer sales data, focusing on customer behaviour, spending patterns, and time-based trends.
Tools

SQL (SQLite)


Analysis Performed

Order sequencing using ROW_NUMBER
Customer ranking using RANK
Running totals over time
Monthly spending trends using LAG
Identification of increasing customer spending


Key Insights

Some customers make repeat purchases
Customer 102 shows increasing spending
Revenue grows steadily over time
A small number of customers contribute most revenue


Skills Demonstrated

Window functions (ROW_NUMBER, RANK, LAG)
Time-series analysis
Advanced SQL query writing
Business insights generation
